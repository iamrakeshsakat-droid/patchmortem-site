Changelog

Every improvement, feature, and fix — in order.

v0.9.0 June 2026 Latest
New features
  • PatchGuard AI agent — contextual help on every dashboard page, powered by Groq/Claude with full data anonymisation
  • Asset tagging with JSONB storage and multi-tag filter support
  • Patch wave time scheduling with configurable blackout windows
  • Self-serve trial signup and plan management
  • Razorpay billing stub with webhook handling
  • Usage metering per tenant with per-plan limits enforced at API level
  • Classification feedback loop — engineers can flag incorrect AI classifications
v0.8.0 June 2026
New features
  • Dashboard UX rebuild — collapsible sidebar, KPI cards, compliance gauges, dark theme system tokens
  • Password reset flow with tokenised email links
  • User invitation system with RDS persistence and 48-hour expiry
  • Brute force login protection (rate limiting + account lockout)
  • CSRF + XSS protection across all form inputs
  • Audit trail search with date range filters and URL-synced state
v0.7.0 May 2026
New features
  • Asset registry RDS persistence — live device inventory stored in PostgreSQL (FIX-A)
  • Notifications, planner, and scraper RDS persistence (FIX-B)
  • Marketing home page with pricing tiers and demo request form
  • Post-login onboarding wizard for new tenant setup
  • Legal documents — Privacy Policy, Terms of Service, DPA, AUP
v0.1.0 April 2026 Initial release
Core platform
  • 8-layer architecture: classifier, rollback engine, audit writer, predictive engine, compliance engine, marketplace, asset registry, patch planner
  • Go agent with heartbeat and patch failure detection
  • HMAC-SHA256 cryptographic audit chain with tamper detection
  • Four-eyes approval enforcement for production rollbacks
  • PCI DSS 6.3, HIPAA 164.312(b), SOC2 CC7.2 compliance report generation
